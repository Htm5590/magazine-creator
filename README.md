**تحواس براس (Tahwas Presse)** هو استوديو ويب متكامل موجه للناشرين، الصحفيين، ومصممي المجلات السياحية والثقافية. يتيح لك بناء وإخراج مجلة ورقية متكاملة بالمقاييس المطبعية العالمية (A4 Sheetfed)، مع إدارة المقالات، التبويب الصحفي، الإعلانات التجارية، وتصدير مجلة PDF رقمية ومطبعية جاهزة بنقرة واحدة — دون الحاجة لخبرة مسبقة في برامج التصميم المعقدة مثل Adobe InDesign.

## 🌟 أبرز المميزات (Features)

<div align="center">
  <img src="https://images.unsplash.com/photo-1469854523086-cc02fe5d8800?auto=format&fit=crop&w=1200&q=80" alt="Editorial & Travel Magazine" width="100%" style="border-radius: 8px; max-height: 280px; object-fit: cover;" />

### 1. 🎨 تصميم الأغلفة والافتتاحية (Cover & Editorial)
- نماذج غلاف صحفية مميزة مستوحاة من كبرى مجلات السفر العالمية (National Geographic Traveler, Geo, وغيرها).
- محرر مرئي للترويسة (Masthead)، العناوين الفرعية (Cover Lines)، الباركود الدولي، السعر، ورقم وتاريخ الإصدار.
- ضبط بؤري ذكي لصور الغلاف (Focal Point Selector) لضمان عدم اقتصاص المعالم الرئيسية.
- صفحة محتويات (Table of Contents) وافتتاحية رئيس التحرير مع صورة وتوقيع شخصي.
- صفحة الغلاف الخلفي (Back Cover) تدعم إعلاناً فاخراً أو رسالة ختامية وشعار المجلة.

### 2. ✍️ إدارة وتحرير المقالات السياحية (Article Management)
- **البدء بدون مقالات تجريبية مسبقة**: يبدأ الاستوديو فارغاً ونظيفاً ليقوم المستخدم بإدخال محتواه الحصري مباشرة.
- تصنيفات سياحية متنوعة (سياحة صحراوية، ساحلية، تراث ومعالم، مغامرات واستكشاف، ثقافة وفنون، خدمات فندقية).
- بطاقة معلومات السفر الميدانية (**Travel Facts Box**): أفضل أوقات الزيارة، الإقامة، المطبخ المحلي، وتنبيهات السلامة.
- معرض صور متعدد لكل مقال مع خيارات ضبط التسميات التوضيحية (Captions) ونسب العرض.

### 3. 📰 قوالب إخراج وتخطيط صحفي ذكية (Magazine Layout Engine)
- دعم قوالب نشر احترافية:
  - **Cover Story Hero**: صفحة افتتاحية ممتدة مع صور بانورامية.
  - **Standard Multi-Column**: تصميم عمودين وثلاثة أعمدة بالمقاييس الصحفية المريحة للقراءة.
  - **Photo Grid Showcase**: شبكة صور متناسقة لعشاق الفوتوغرافيا السياحية.
  - **Travel Guide & Practical**: تخطيط إرشادي مدمج بالخرائط والإحداثيات.
- حساب فوري وتلقائي لتوزيع الصفحات ونسب الكثافة التحريرية لمنع الفراغات أو فيض النصوص.

### 4. 📢 إدارة المساحات الإعلانية والشراكات (Ad Manager)
- إضافة إعلانات قياسية طباعياً: صفحة كاملة (Full Page)، نصف صفحة (Half Page)، أو ربع صفحة (Quarter Banner).
- تتبع العائد المالي التقديري للعدد من خلال لوحة تحكم مخصصة.
- خوارزمية ذكية لمنع تصادم الإعلانات مع المواد التحريرية الحساسة.

### 5. 🔍 فحص ما قبل الطباعة (Preflight Print Checker)
- تدقيق أوتوماتيكي قبل إرسال الملف للمطبعة:
  - التحقق من دقة الصور وتجنب الصور منخفضة الجودة.
  - التأكد من مضاعفات صفحات المجلة المناسبة للطي والتجليد (4 أو 8 أو 16 صفحة).
  - كشف نصوص التجاوز أو الصور المفقودة.

### 6. 🖨️ تصدير PDF فائق الدقة (Ultra-High Resolution PDF Export)
- توليد ملف PDF بمعيار الطباعة (300 DPI Rendering) متوافق مع المطابع التجارية.
- دعم علامات القص (Crop Marks) وهوامش الأمان للقطع (Bleed Margins).
- وضع المعاينة الرقمية التفاعلية بتقليب الصفحات ككتاب واقعي.

### 7. 🔒 الخصوصية والأمان الكامل لمفاتيحك (Zero API Leakage)
- يعمل التطبيق محلياً وبشكل مستقل دون أي استهلاك لمفاتيحك الخاصة.
- إمكانية تفعيل المساعد الذكي Google Gemini بشكل اختياري بمفتاح الزائر الخاص (Byo-Key) مع الحفظ في المتصفح حصراً.

## 🧭 مسار العمل خطوة بخطوة (Workflow)

```
[ الخطوة 1: هوية العدد ] ➡️ [ الخطوة 2: صياغة المقالات ] ➡️ [ الخطوة 3: إدارة الإعلانات ] ➡️ [ الخطوة 4: التخطيط الفني ] ➡️ [ الخطوة 5: التصدير والطباعة ]
       Cover & Setup              Articles & Stories                Ads & Sponsors               Layout & Preflight              PDF Generation
```

<div align="center">
  <img src="https://images.unsplash.com/photo-1512453979798-5ea266f8880c?auto=format&fit=crop&w=1200&q=80" alt="Print Layout & Proofing" width="100%" style="border-radius: 8px; max-height: 250px; object-fit: cover;" />
</div>

1. **الخطوة الأولى (هوية العدد):** تحديد رقم العدد، تاريخ الصدور، أسعار النسخة، صياغة عنوان الغلاف واختيار صورته الرئيسية.
2. **الخطوة الثانية (المقالات والتقارير):** كتابة المقالات، إضافة التفاصيل التحريرية، الكاتب، وصناديق إرشادات الزيارة.
3. **الخطوة الثالثة (الإعلانات):** إدراج الرعاة والشركاء التجاريين وتحديد حجم الإعلان المخصص لكل راعٍ.
4. **الخطوة الرابعة (المعاينة والتدقيق):** تصفح المجلة في عارض الصفحات، تشغيل فحص Preflight لمعالجة أي ملاحظات فنية.
5. **الخطوة الخامسة (التصدير للطباعة):** استخراج ملف الـ PDF الجاهز للمطبعة أو مشاركة نسخة رقمية عالية الدقة.

## 🛠️ البنية التقنية (Tech Stack)

| المجال | التقنية المستخدمة | الوصف |
|---|---|---|
| **الواجهة الأمامية** | React 19 + TypeScript | بنية تفاعلية حديثة فائقة السرعة |
| **محرك البناء** | Vite 8 | تجميع وتحديث فوري للوحدات البرمجية |
| **التنسيق والتصميم** | Tailwind CSS v4 | نظام أنماط حديث يدعم الـ RTL وخط القاهرة (Cairo) |
| **مكتبة الأيقونات** | Lucide React | أيقونات متجهة عالية النقاء |
| **محرك تصدير PDF** | pdf-lib + html2canvas-pro | تصيير الصفحات إلى PDF طباعي عالي الجودة |
| **المساعد الذكي** | Google Gemini API (`@google/genai`) | صياغة واقتراح العناوين والمراجعة اللغوية (اختياري) |

## 💻 طريقة التثبيت والتشغيل محلياً (Installation)

### المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مدير الحزم `npm` أو `yarn` أو `pnpm`.

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the Repository):**
   ```bash
   git clone https://github.com/your-username/tahwas-presse-studio.git
   cd tahwas-presse-studio
   ```

2. **تثبيت الحزم البرمجية (Install Dependencies):**
   ```bash
   npm install
   ```

3. **بدء خادم التطوير المحلي (Start Dev Server):**
   ```bash
   npm run dev
   ```
   سيتم تشغيل التطبيق محلياً على: `http://localhost:3000`

4. **بناء المشروع للإنتاج (Build for Production):**
   ```bash
   npm run build
   ```

## 🚀 طرق النشر (Deployment)

يمكنك نشر هذا التطبيق بسهولة على أفضل منصات الاستضافة السحابية:

### النشر على Vercel (موصى به)
1. قم بربط مستودع GitHub الخاص بك بمنصة [Vercel](https://vercel.com).
2. سيتم التعرف على إعدادات `Vite` تلقائياً.
3. اضغط على **Deploy** وسيعمل موقعك مباشرة مع شهادة SSL مجانية وإمكانية ربط نطاقك المخصص (`yourmagazine.dz`).

### النشر على Netlify
1. اسحب مجلد `dist` بعد تنفيذ `npm run build` أو اربط المستودع بـ [Netlify](https://netlify.com).
2. اجعل أمر البناء `npm run build` ومجلد النشر `dist`.
